# SmartBudgetManager
A project for managing Budget.

1) Overview
Smart Budget Manager is an Excel-based tool designed to help users manage their personal finances. It allows users to record income and expenses, organize transactions by category, monitor their monthly budget, and view financial summaries through a dashboard.

2) Main Features
Income and Expense Tracking: Record financial transactions with dates, descriptions, and amounts.
Expense Categorization: Organize expenses into categories such as Food, Transport, Rent, Health, and Education.
Automatic Calculations: Calculate total income, total expenses, and the monthly balance.
Dashboard: View financial summaries and expense charts.
Budget Monitoring: Compare actual expenses with budget limits and display a warning when the overall budget is exceeded.

3) System Requirements
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
A computer capable of running the selected spreadsheet application.
Basic knowledge of using spreadsheets.
